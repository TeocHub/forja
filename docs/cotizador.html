Componentes

Cómo se calcula

Proveedor en Chile: precio + envío. Si el precio no incluye IVA, se suma 19%.

Proveedor extranjero: se convierte a pesos con el dólar indicado. Hasta USD 500 (precio + envío) se suma 19% de IVA. Sobre USD 500 se suma 6% de arancel y luego 19% de IVA sobre ese total. Es una estimación: el valor exacto lo define Aduanas y puede haber cargos del courier.

Estimación de otras cantidades: con dos o más cotizaciones de un mismo proveedor, se calcula un costo fijo (preparación, planchas) y un costo por unidad, y con eso se estima cualquier cantidad. Mientras más cotizaciones, mejor la estimación.
